# Mama’s Shop 3D illustration assets

Each PNG is an individual transparent crop from the original icon sheet.

- `inventory/`: cart and stock states
- `sales/`: sales activity
- `payments/`: payment methods and cash collection
- `credit/`: customer credit
- `reminders/`: due payment reminders
- `sync/`: offline, syncing, and connection states
- `family/`: seller and access management
- `reports/`: analytics state

Source sheet: `../source/shop-management-icon-pack.png`
