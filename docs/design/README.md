# Product design reference

This app's approved UI/UX design is the source of truth for screen layout, visual styling, interaction states, and navigation affordances. Developers and coding agents should consult it before implementing or changing product screens.

**Reference status:** No design link or design export was present in the repository when this file was created. Add the approved Figma URL here, or place exported reference files in this directory and link them below. Do not treat the scaffold placeholder screens as the final design.
